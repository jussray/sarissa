This does not change `skill v1`, the archival registry, the manual handoff contract, or execution authorization. Production hosting does not imply operational security capability.

Build: none. Cloudflare Pages output: `site/`. Rollback: revert the website-only commit or select a previous known-good Pages deployment. No DNS or Access-policy changes required.
