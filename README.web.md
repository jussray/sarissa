# Sarissa web frontend

V11 approved artwork, unchanged at the asset-byte level. Static offline demonstration only: no account provisioning, external operations, or access to systems. All existing registry material remains unchanged.

Serve `site/` over HTTP for local review. For Cloudflare Pages use `site` as the output directory with no build command. The included `wrangler.jsonc` is an alternative Workers static-assets configuration; use only one hosting method. Do not deploy over an existing unrelated resource. No production identity provider is configured.
